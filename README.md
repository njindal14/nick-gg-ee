Steps to run the code for master plots:
1. Run `root -l SLAna.C`, which calls on `SLAnalyze.cxx` and creates plots from a `slight.out` file. Be sure to change local paths to your `slight.out` file in both files. The output of this file is saved locally in `SL_plotsBetter.root`.
2. Run `root -l PairEff.C`. This analyzes the output files of STAR simulation `FemtoDst` files (both MC and reconstructed events), and saves the plots locally in `simulation_plots.root`. The plots it saves concern the pair efficiency and track data for NHitsFit and NHitsDedx, as well as the azimuthal Phi variable. The rest of the macros in this repo can be run in any order.
3. `TPCCheck.C` takes the previously created `simulation_plots.root` and uses the phi variable to check the TPC sector acceptance for issues in simulation and data and compares the two for forward and backward rapidity. It also checks NHitsDedx and NHitsFit for data and simulation and compares them in different pT bins. 
4. Later one can run `root -l masterPlots.C`. This takes as input the previously created `SL_plotsBetter.root` and `sim_plots.root`, and does some basic analysis code on a data `PairDst` file, for which you should change the path to point to your local data file if you don't have it. I am working on modifications to this file such that it takes as input `simulation_plot.root` from running `PairEff.C` and removes the redundancies present in `simAnalysisAndEfficiencies.C`. I am considering removing the previous file altogether as I modify this structure.
